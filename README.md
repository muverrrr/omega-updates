# OMEGA NEXT — официальный канал обновлений

Репозиторий обновлений OMEGA NEXT для Android/Termux.

- **Игра** работает локально; личные сохранения SQLite и ключи OpenRouter **не публикуются**.
- **Менеджер обновлений**: `omega_updater/start.py`, адрес `http://127.0.0.1:8766/updates`.
- **Настройка канала** в менеджере: `muverrrr/omega-updates`.
- Новые версии выпускаются через GitHub Releases в виде `omega-update.zip`, проверяемого SHA-256.
- Менеджер делает резервную копию баз перед установкой и требует подтверждения.

## Публикация

Версия обновления должна быть **новее 3.0.0**. GitHub Actions (`.github/workflows/publish.yml`) проверяет подготовленный релиз в `releases/vX.Y.Z/omega-update.zip.b64` и публикует бинарный ZIP.

**Не загружайте сюда** SQLite-базы, пользовательские диалоги, файлы `saves`, `.private-ai.json` или API-ключи.

До первой публикации нового релиза менеджер не будет предлагать установку — это нормально.
