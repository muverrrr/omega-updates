# OMEGA NEXT 4.0.1 — исправление интерфейса

- Исправляет ситуацию, когда OMEGA UPDATE 1.0 запускает новую логику версии 4.0, но показывает заголовок и HTML версии 3.0.
- Восстанавливает скрипт и оформление блока знаний NPC в интерфейсе 4.0.
- Сохраняет прежние базы SQLite, журнал Core, настройки OpenRouter и подтверждённую смерть Тоуки.
- Новая папка `omega_v5` используется исключительно как неизменяемый модуль патча 4.0.1; она создаёт обновлённую страницу из уже установленного интерфейса 3.0.
- Устанавливайте через OMEGA UPDATE → проверить → скачать → подтвердить установку.
